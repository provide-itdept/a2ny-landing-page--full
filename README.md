# A2NY IT WORKS

A maintainable React + Express starter for A2NY IT WORKS.

## Structure

- `client/` — Vite React frontend, reusable components, routes, SEO metadata, and responsive styles.
- `server/` — Express API, modular routes, validation, security middleware, and PostgreSQL-ready data layer.

## Run locally

1. Install dependencies with `npm install`, `npm --prefix client install`, and `npm --prefix server install`.
2. Copy `.env.example` to `.env` and adjust database settings when PostgreSQL is available.
3. Run `npm run dev`.

The frontend runs on `http://localhost:5173` and the API on `http://localhost:4000`.
